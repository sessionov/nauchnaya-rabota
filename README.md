# Роль музыки в становлении личности Абая

Сайт научного проекта Камиля Валеева (11 класс, школа имени Абая, Костанайская область, 2026; научный руководитель Т. Б. Левит). Полный текст работы, презентация защиты, список литературы, поиск и материалы для тех, кто продолжает тему.

## Стек

- Next.js 16 (App Router, все страницы генерируются статически), TypeScript, Tailwind CSS 4, компоненты shadcn/ui на Radix.
- Контент: Markdown в `content/sections/*.md`, разбирается при сборке (unified/remark/rehype, KaTeX подключён для формул на сервере; в этой работе формул нет).
- Шрифт Literata (кириллица, латиница, казахские буквы) через `next/font/local`.
- Поиск: индекс `/search-index.json` собирается при сборке, ищет MiniSearch в браузере.

## Запуск

```bash
npm install
npm run build
npm run start   # http://localhost:3000
```

## Деплой на Vercel

1. Залейте папку проекта в репозиторий GitHub (без `node_modules` и `.next`).
2. На vercel.com: Add New → Project → выберите репозиторий. Фреймворк определится как Next.js, настройки менять не нужно.
3. Необязательно: переменная окружения `NEXT_PUBLIC_SITE_URL` с адресом сайта (например, `https://abai-music.vercel.app`). Без неё для sitemap и Open Graph берётся адрес production-деплоя Vercel.

Оригинал презентации (PDF, 76,5 МБ) в репозиторий не включён: он слишком большой для загрузки. На сайте для скачивания доступна облегчённая копия `public/files/valeev-prezentatsiya-2026-lite.pdf` (4 МБ).

## Где что лежит

| Путь | Что это |
| --- | --- |
| `content/sections/` | Текст работы по разделам, перенесён из docx без изменений (только разметка) |
| `content/sources-md.json` | Список литературы в точности как в работе |
| `lib/site.ts` | Данные с титульного листа, файлы для скачивания, строка ГОСТ |
| `lib/slides.ts` | Расшифровка текста всех 18 слайдов |
| `lib/sources.ts` | Источники, результат проверки ссылок, места упоминания |
| `lib/glossary.ts` | Глоссарий; каждое определение при сборке сверяется с текстом работы |
| `public/slides/` | Слайды презентации в WebP |
| `public/files/` | Работа (PDF, DOCX) и презентация для скачивания |
| `tests/e2e.py` | Сквозной тест production-сборки (Playwright) |

## Проверки

```bash
npm run build && npm run start
python3 tests/e2e.py   # нужен Python с playwright и установленный Chrome
```

Сборка падает, если цитата на странице «Для продолжателей» или в глоссарии не совпадает дословно с текстом работы.
